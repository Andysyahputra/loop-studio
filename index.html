Mode Buat Kode Sendiri — kanvas kosong

Kode di bawah dijalankan tiap frame sebagai draw(ctx, time, w, h) — di sini variabelnya ctx, t, W, H, P. Preview langsung jalan saat kamu mengetik. Pakai sin(TAU*t*k) (k bilangan bulat) supaya loop-nya mulus.

Sisipkan snippet: klik untuk menambah contoh ke posisi kursor di editor.

Bantuan singget: lingkaran ctx.arc(x, y, r, 0, TAU) · gelombang sin(x*0.008 + TAU*t*2) · partikel rng(seed) buat posisi tetap · warna P.c1 / P.c2 / P.c3, transparan A(P.c1, 0.5), campur mix(P.c1, P.c2, 0.5). Cara kerja & fungsi bantuan

Kode di atas adalah isi fungsi gambar yang dipanggil setiap frame. Ubah, lalu tekan Terapkan Kode (atau Ctrl+Enter) — pratinjau langsung berubah. Kode juga otomatis diterapkan ~0,6 detik setelah kamu berhenti mengetik.

  • ctx — konteks canvas 2D untuk menggambar
  • t — posisi loop, dari 0 sampai 1, lalu kembali ke 0
  • W, H — lebar & tinggi kanvas (piksel)
  • P.bg, P.c1, P.c2, P.c3 — warna dari palet
  • sin(), cos(), TAU — trigonometri; pakai TAU*t supaya gerakannya nyambung
  • lerp(a,b,p), clamp(v,min,max) — interpolasi & batas nilai
  • A(warna, alpha) — warna hex jadi transparan, mis. A(P.c1, 0.5)
  • mix(w1, w2, p) — campur dua warna hex
  • rng(seed) — pembangkit angka acak tetap (sama setiap frame)

Trik loop mulus: setiap gerakan periodik pakai sin(TAU*t*k) atau cos(TAU*t*k) dengan k bilangan bulat — dijamin frame terakhir nyambung ke frame pertama.
