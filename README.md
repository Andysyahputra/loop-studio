# Loop Studio

✨ Video loop cantik, dibuat dari kode | 10–60 detik, mulus tanpa jeda | Untuk kreator & penjual stock

Studio nyieun video loop tina motion code, langsung di browser — tanpa install, tanpa server.

## Fitur
- 8 preset motion code (Gelombang Aurora, Orbit Partikel, Kisi Denyut, Teks Kinetik, Kaleidoskop, Spiral Galaksi, Blob Cahaya, Bar Ekualiser) — kodena bisa diédit, preview langsung jalan
- 5 palet warna + warna manual + acak
- Rasio 9:16 / 1:1 / 4:5 / 16:9, kualitas 720p / 1080p
- Kontrol putar / jeda / scrub / lengkah frame
- Ekspor: Rekam Video MP4/WebM satu putaran penuh, unduh frame PNG, unduh / salin kode .js

## Pakai
Buka situsna, pilih preset, édit kode lamun hayang, terus pencét Rekam Video.
